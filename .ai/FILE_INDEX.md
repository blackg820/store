## Safe Edit Guidance

- Prefer narrow edits in the listed file for the feature.
- Update resources and TS DTOs together.
- Update migrations/seeders when DB or billing shape changes.
- Update `.ai` docs after meaningful changes.

## Dangerous Areas

- Tenant middleware and global scopes.
- Public checkout product/price validation.
- Subscription enforcement and feature aliases.
- Auth token refresh/logout behavior.
- Al-Waseet credential/token handling.
- Any owner-input translation fields.
